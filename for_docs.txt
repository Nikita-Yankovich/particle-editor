Схема системы доступа к данным (Model):

Для каждой открытой сцены SceneManager создаёт новый временный файл.
Отличается он единственным разделом с двумя графами в начале - "путь к оригинальному файлу" (source_scene) и "сохранён ли этот файл" (is_saved).
Программа не умеет читать файлы без этой графы или с этой графой продублированной более одного раза.
Таким образом, программа может читать только временные файлы, которые являются копиями открываемых файлов сохранений.

За открытие файла (создание временного файла и перекопирование данных туда, создание там графы is_saved) отвечает метод open_scene
За чтение и передачу объектов со сцены в контроллер отвечает метод load_scene

При любом редактировании сцены графа is_saved во временном файле переходит в значение false.
При сохранении сцены (save_scene или save_scene_as) графа is_saved обратно переходит в true.

При штатном закрытии сцены через метод close_scene поведение программы зависит от значения is_saved.
Если сцена сохранена (is_saved = true), то программа закрывает сцену и удаляет временный файл.
Если сцена не сохранена (is_saved = false), то программа спрашивает, хочет ли пользователь сохранить сцену, сохранить во временном файле или удалить изменения (запрос происходит через UI).

При закрытии программы несохранённые временные файлы не удаляются!
Если при открытии программы остаются несохранённые временные файлы, то программа сразу просит их сохранить.
При внештатном закрытии программы (Alt + F4, снятие задачи через диспетчер задач) остаются все временные файлы, включая сохранённые.
В таком случае пользователь может сам убедиться, сохранились ли его последние изменения или нет перед открытием программы.
Все сохранённые временные файлы удалятся при следующем закрытии программы. По мере работы эти файлы можно перезаписывать при возвращении к работе над сценой.

@staticmethod _delete_working_file - удаляет временный файл (только при необходимости), внутренний статический метод.

!ВАЖНО: программа не предназначена для ручного вмешательста в графу is_saved временного json-файла.
Случаи, когда постоянный и временный файлы не совпадают, а is_saved = true, недопустимы при нормальной работе программы.
Тем не менее, такие случаи возможны при недостатке памяти на компьютере, ошибках с файловой системой и аварийном завершении программы в момент сохранения.
